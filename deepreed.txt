!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!Постоянный сервис (основной режим)
Запуск в активном режиме (видно все логи)
python3 main.py


С подробным логом
python3 main.py --debug

!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!Фоновый режим (без привязки к терминалу):

 Запуск в фоне
nohup python3 main.py > /dev/null 2>&1 &

 Посмотреть PID процесса
echo $!

 Проверить что работает
ps aux | grep main.py

 Следить за логами
tail -f logs/ecmwf_download.log

 Остановить
kill $(pgrep -f main.py)

!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!РАЗОВАЯ ЗАГРУЗКА 

 За сегодня
python3 main.py --once

 За конкретную дату
python3 main.py --once --date 20260730

 С отладкой
python3 main.py --once --date 20260730 --debug


!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!Systemd сервис (автозапуск при старте системы):

) Создать файл сервиса (
sudo nano /etc/systemd/system/ecmwf-loader.service

Вставить:

[Unit]
Description=ECMWF Data Loader Service
After=network.target

[Service]
Type=simple
User=user
WorkingDirectory=/home/user/Desktop/YKI/ecmwf-minio-loader
ExecStart=/home/user/Desktop/YKI/ecmwf-minio-loader/venv/bin/python3 main.py
Restart=always
RestartSec=30

[Install]
WantedBy=multi-user.target



!!!!!!!! Применить и запустить
sudo systemctl daemon-reload
sudo systemctl enable ecmwf-loader
sudo systemctl start ecmwf-loader

!!!!!!!!!! Управление:
sudo systemctl status ecmwf-loader    Статус
sudo systemctl stop ecmwf-loader      Остановить
sudo systemctl restart ecmwf-loader   Перезапустить
journalctl -u ecmwf-loader -f         Логи сервиса


!!!!!!!!!!!!!!!!!!!!!!!!Просмотр статистики и логов:
 Логи в реальном времени
tail -f logs/ecmwf_download.log

 Последние 50 строк
tail -50 logs/ecmwf_download.log

 Поиск ошибок
grep "ERROR" logs/ecmwf_download.log

 Поиск успешных загрузок
grep "Загружен в Minio" logs/ecmwf_download.log
